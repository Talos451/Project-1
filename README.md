# Project-1
 College Recruitment Study
Perform exploratory data analysis on CCM Computing Courses Entry Surveys. Provide insight using the data from the analysis that could increase enrollment in computing classes. 
This project looks at survey data to figure out what drives student interest in taking more computing classes. It compares computing and non-computing majors, checks which intro classes spark the most interest, and analyzes how students heard about the school.
You can find the code and plots used in analysis under the project_1_part_3.ipynb, and the cleaned data CSV under Majors_2024_Cleaned.csv.
